# Combat material atlas

`combat-atlas-v1.png` was generated with the built-in image_gen tool and copied into this project. No original CF textures were extracted. The runtime crops its quadrants into demon armor, gunmetal, engraved forearm armor and red leather materials. Mesh UVs consume these materials; the image is not used as a billboard character.

## Exact generation prompt

Use case: stylized-concept. Asset type: a single square game material atlas to UV map onto actual 3D meshes, NOT concept art, not a character sheet. Create a precise 2 by 2 grid of four equal square material swatches filling entire image, no gutters, no borders, no text. Upper left quadrant: dark crimson blackened fantasy demon armor, elongated overlapping chitin scales, subtle scratched glossy red edges, narrow orange ember cracks, predominantly near-black burgundy. Upper right: graphite gunmetal sword surface, fine longitudinal brushed metal grain, restrained silver abrasions and inset mechanical seams, mostly dark grey with no symbols. Lower left: dark charcoal forearm armor with elegant ivory silver curling inlaid filigree and a few deep crimson flowing accent lines, flat orthographic material. Lower right: deep red leather glove surface, fine leather grain and curved reinforced stitched seams. High fidelity realistic game texture, flat even albedo-style lighting, sharp small surface detail, no baked perspective, no objects or scenery, no UI, no letters, no watermarks. Exactly four square quadrants.

The procedural architecture materials are separate from this atlas.
