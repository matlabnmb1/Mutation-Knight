# Ghost Blade — Windows prototype

第一人称近战与跑酷实验项目。Windows x64 / .NET Framework 4.8，使用 WPF 三维渲染。

## 运行

解压整个玩家包，运行 `BioSwordsman3D.exe`。不要单独移动 exe，`assets` 必须与它放在一起。程序未签名；下载者应核验来源，不应为了运行它而关闭系统安全防护。

## 操作

WASD 移动，鼠标观察；左键轻击/突刺/一闪，右键重击/格挡；F 立即切换姿态；空格跳跃/御剑式突进；Ctrl 下蹲（空中收腿）；F2 灵敏度及目标帧率设置；[ ] 或 - + 微调；Esc 暂停；F5 重置；F6 训练/生存；M 静音；F11 全屏。

## 构建和检查

在 Windows PowerShell 中运行 `./build-3d.ps1`。可执行文件支持 `--test`、`--verify`、`--benchmark`。测试结果写入 `verification-tests.txt`，渲染输出到 `verification`。

## 当前限制与素材说明

公开包使用合成击杀确认音，不包含本地 CF 连杀语音。程序支持可选 `local-audio/streak-2.wav` 至 `streak-8.wav`（22050 Hz、单声道、16-bit PCM），缺失时自动回退。F2 中可试听已安装的本地语音。

这是非官方机制重建原型，与 CrossFire/穿越火线及其权利方无关联。模型为程序生成，材质图集为 AI 生成，音效为合成音；不是官方素材提取包。图集来源与提示词见 `assets/README.md`。参考角色形象及相关名称不因此成为本项目所有；发布者需自行确认适当的素材和名称使用范围。本项目暂未指定开源许可证。

目标 60/120 不保证稳定达到：大量敌人近距离重叠仍有明显帧率瓶颈。地图、动作和碰撞仍处于原型阶段，欢迎提供复现步骤。
